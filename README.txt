AURELIS — Luxury Watch Scroll Website

Included:
- index.html
- style.css
- script.js
- frames/ (240 supplied frames)

How to run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Use VS Code Live Server on index.html (recommended).
4. Scroll through the hero section to control the watch animation.

The hero uses the supplied frame sequence and smoothly interpolates between frames for a cinematic scroll effect.
